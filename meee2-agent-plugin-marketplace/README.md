# Meee2 Marketplace

Official Meee2 agent plugin marketplace for Claude Code and Codex.

## Codex

```bash
codex plugin marketplace add tianqixinxi/meee2-marketplace
codex plugin add meee2@meee2-official
```

## Claude Code

```bash
claude plugin marketplace add tianqixinxi/meee2-marketplace --scope user
claude plugin install meee2@meee2-official --scope user
claude plugin install meee2-workflow-bridge@meee2-official --scope user
claude plugin enable meee2@meee2-official --scope user
claude plugin enable meee2-workflow-bridge@meee2-official --scope user
```
