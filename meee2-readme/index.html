System architecture

从本机 AI 工具到团队协作现场

meee2 的关键不是再发明 agent runtime，而是观察真实工作、建立 Session Graph，并按用户选择同步到团队视图。

Claude Code / Codex / Cursor / OpenClaw 用户保持原工作方式，session 真实发生在本机。
session discovery / transcript reader / permission bridge 发现 session、解析最近消息、判断状态、保留跳回 terminal / IDE 的能力。
session / repo / status / risk / output / handoff 把散乱 session 转成可过滤、可审查、可接力的工作图谱。
private / metadata / summary / recent context / full / artifacts 同步级别是一等边界，默认不上传完整 transcript。
Personal Cockpit / Team Radar / Workroom / Review / Memory 先让个人 5 分钟 aha，再把公开 AI 工作变成团队 work radar。
summary / blocker / handoff / standup / reviewer brief 不是再加聊天框，而是把 transcript 转成协作记忆。
Feishu IM cards / Feishu docs 外部协作第一版只做飞书生态；GitHub / Linear / Jira 先保留 evidence 占位。

Core model

Session 是第一对象

Task / Issue / PR 是上层意图；session 才是真实执行单元。一个目标可以关联多个 session，一个 session 可以产生多个证据。

Session

AI 工作执行单元

  • who: owner / agent / machine
  • where: repo / branch / cwd / terminal
  • what: title / goal / current step / status
  • output: diff / commit / PR / test / deploy
  • risk: permission / blocked / failed / context low
  • handoff: compact context / resume point

Session Graph

Workroom

替代旧 global session / channel

Workroom 是围绕 1-N 个真实 session 的临时协作现场，可生成 combined handoff、rescue context 和 reviewer brief。

Evidence

先可信，再统计

优先沉淀 changed files、测试结果、PR、deploy 和 failed attempts。analytics 必须建立在可信证据之后。

Feishu-first external integration

真实外部集成先只做飞书生态

本机不直连飞书，也不保存 app secret。本机只上传 sync policy 允许的 payload，由 meee2 Online 负责发飞书 IM 卡片和飞书文档。

meee2 不把所有人拉进同一个 transcript 流，而是根据角色展示状态、风险、证据和接力点。

Roadmap

从本地 aha 到团队 AI 工作记忆

Phase 0 Remove Channel Capability

清掉旧 A2A channel / msg / 白板协作心智。

Phase 1 Personal AI Cockpit

本地发现、状态分组、jump back、permission/blocked 提醒。

Phase 2 Selective Sync + Team Radar

session 级 sync policy，团队可见的 active / blocked / done。

Phase 3 Workroom + Handoff

选中多个 session 创建临时协作现场，生成 rescue / handoff context。

Phase 4 Feishu Evidence Output

飞书 IM 卡片、飞书文档、reviewer brief、daily standup。

Phase 5 Team Memory & Audit

历史搜索、retention、audit、self-host / enterprise controls。
